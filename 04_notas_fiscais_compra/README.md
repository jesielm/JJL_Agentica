# Notas Fiscais de Compra / Fornecedores

Base documental e estruturada das compras realizadas pela JJL.

## Organização
`YYYY/MM/<fornecedor>/<chave-ou-numero>/`

Cada NF deve manter, quando disponível:
- documento fiscal original (XML preferencialmente e PDF/DANFE complementar);
- arquivo Markdown estruturado para consulta rápida por IA;
- referência ao e-mail de origem.

## Uso operacional
Esta base sustenta consultas como:
- de quem compramos este produto pela última vez?
- qual foi o último preço de compra?
- quanto compramos de determinado fornecedor/produto?
- evolução de preços;
- comparação custo de compra x preço de venda da OC;
- identificação de NF de fornecedor sem DDA e demais conciliações futuras.

A descrição original do documento fiscal nunca deve ser substituída pela descrição normalizada.
